# Росток 1.1 · MVP помощника роста фермера

Три действия на сегодня с объяснением, сценарным эффектом и обязательным подтверждением. Локальные Qwen 0.5B/1.5B, 4 демо-хозяйства, расширенная аналитика, прогноз спроса и сценарный симулятор. Концепт для РСХБ.цифра, не официальное внедрение.

## Работает

* ИИ-помощник: WebLLM/Qwen 2.5 0.5B и 1.5B, 12 готовых задач, потоковый ответ, остановка, проверка и копирование черновика.
* Четыре демо-хозяйства с отдельными локальными рабочими пространствами: молочная ферма, овощи, пасека, пекарня.
* Аналитика: 16 показателей, линейные/кольцевые/пузырьковые диаграммы, тепловая карта и ABC-анализ с пояснениями.
* Прогноз 7/14/30 дней, два метода, MAE/WAPE на rolling backtest, учёт срока партии и неопределённости.
* Сценарий «А что, если»: цена, изменение спроса, расходы, маржа, необходимый объём.
* Три приоритета из пяти классов сигналов, смена фокуса, формулы и источники, скрытие дубликатов, отложить и отклонить с причиной.
* Ассортимент: редактирование/добавление товара, фильтры, поиск, остатки, срок партии, себестоимость, заполненность и фото.
* Продажи за 7/28 дней, график, рейтинг товаров, отчёт TXT.
* Обезличенные клиентские сегменты, сообщения трёх тонов с подтверждением перед копированием.
* Калькулятор скидки с запретом цены ниже/на уровне себестоимости, калькулятор набора с проверкой остатков и подтверждением.
* Локальный план, ручное выполнение и наблюдаемый результат, экспорт журнала JSON.
* Импорт JSON/CSV с предпросмотром, валидацией и подтверждением замены, экспорт и шаблон CSV.
* Три учебных сценария, обучение при первом входе, глобальный поиск, снижение анимаций, адаптивная навигация.

## Запуск

### Docker



```sh

docker compose up --build -d

```



Откройте http://localhost:8000. Остановка: docker compose down. Docker Desktop должен быть запущен. Образ скачивается при первой сборке.



### Статическое приложение без npm-зависимостей:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Открыть http://localhost:8000. Нельзя запускать двойным кликом index.html: ES-модулям и fetch нужен HTTP. Для тестов Node.js 22+:

```sh
npm test
```

## Честные границы

Это рабочий локальный интерактивный MVP с объяснимыми правилами. Подключены локальные LLM через WebLLM. CRM и площадки не подключены. Нет реальных отправок, закупок, публикаций, серверного хранения, SSO и неизменяемого аудита. Демо вымышленное. Сценарные диапазоны не являются доказанным или гарантированным эффектом. Индекс надёжности не является вероятностью.

Данные остаются в браузере текущего origin; локальное хранилище не зашифровано приложением. Экспортируйте JSON и журнал, не очищайте браузер до сохранения. Данные/журнал не синхронизируются между устройствами. JSON импортирует данные, а не доверие/историю подтверждений.

## Документы

* dist/rules.md: формулы, пороги, допущения, исследование и план проверки качества.
* dist/data-contract.json: JSON Schema импорта.
* docs/INTEGRATION.md: план подключения серверного контура и API.
* docs/VALIDATION.md: фактическая проверка и ограничения.

Путь dist содержит все необходимые статические файлы. Runtime WebLLM и WASM включены в dist/llm; веса Qwen загружаются с фиксированных ревизий Hugging Face по действию пользователя. Требуются WebGPU, около 1 ГБ GPU-памяти для 0.5B и около 2 ГБ для 1.5B. Шрифты системные, внешние скрипты не используются. Сводка фермы передаётся локальной модели на устройстве, не облачному API.

Первое скачивание: около 300 МБ для 0.5B, около 1 ГБ для 1.5B; нужен интернет и место в кэше браузера. Массовая доступность на всех устройствах не гарантируется. Полный GPU-прогон в среде подготовки невозможен (нет WebGPU). Прогноз спроса рассчитывается отдельным алгоритмом, не LLM.

Сторонние компоненты: docs/THIRD\_PARTY.md.
