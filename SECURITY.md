# Безопасность

MVP хранит данные в localStorage текущего браузера без шифрования приложением. Используйте обезличенные наборы и экспортируйте резервную копию. Четыре демо-профиля не являются отдельными защищёнными учётными записями.

ИИ работает на устройстве через WebGPU. Только веса модели загружаются с Hugging Face. Проверяйте каждый ответ. У модели нет инструментов выполнения действий. Все изменения за пределами приложения требуют будущих серверных адаптеров.

Импорт проверяет типы, диапазоны, ссылки и размеры. Текст выводится с экранированием. CSP размещена в index.html. Docker работает без root и слушает только localhost в compose. Для публичного хостинга нужны HTTPS и актуальные зависимости. Не публикуйте .env, ключи, клиентские данные и экспортированный журнал в GitHub.

Серверная авторизация, изоляция организаций, защищённый аудит и резервное копирование пока не реализованы. План: docs/INTEGRATION.md. Уязвимости сообщайте владельцу репозитория приватно через GitHub Security Advisories, если функция включена.
